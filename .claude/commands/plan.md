# Plan Command

Manually activate TDD Planner Agent.

## Usage
```bash
/plan <task>
```

## Examples
```bash
/plan implement user login
/plan add JWT auth
/plan improve payment API
```

## Actions

Launch TDD Planner (@.claude/agents/tdd-planner.md):
1. 🔍 Research
2. 🧠 Analyze
3. 📊 Decompose to issues
4. 📝 Generate TDD plans
5. ✅ Request approval
